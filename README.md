# 🚢 Titanic Survival Analysis — Exploratory Data Analysis

## 📌 Project Overview
This project explores the Titanic passenger dataset to understand the factors associated with passenger survival. Using Python and data visualization, we analyze survival patterns based on gender, passenger class, age, fare, and family size.

## 🎯 Objectives
- Analyze passenger survival rates.
- Compare survival rates by gender and passenger class.
- Explore the relationship between ticket fare and survival.
- Investigate how family size relates to survival.
- Handle missing values and create useful features.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📂 Project Files
- `Titanic_EDA.ipynb` — Notebook containing data cleaning, analysis, and visualizations.
- `train.csv` — Dataset used for the analysis.

## 📊 Key Findings
- Overall survival rate was approximately **38.38%**.
- Female passengers had a higher survival rate (**74.20%**) than male passengers (**18.89%**).
- First-class passengers had a higher survival rate (**62.96%**) than second-class (**47.28%**) and third-class passengers (**24.24%**).
- Passengers travelling in small families had a higher observed survival rate than those travelling alone or in large families.
- Cabin information availability was associated with survival, although passenger class may partly explain this relationship.

## 📝 Conclusion
This project demonstrates how Exploratory Data Analysis can reveal patterns and relationships in real-world data. The findings describe associations and do not establish causation.
